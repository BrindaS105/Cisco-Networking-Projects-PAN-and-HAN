
# Home Area Network (HAN) Using Cisco Packet Tracer

## Introduction

A Home Area Network (HAN) connects multiple electronic devices within a residential environment.

This project demonstrates a smart home network designed using Cisco Packet Tracer.

The topology includes a Home Gateway, smartphone, IoT fan, and IoT light.

## Project Objective

The main objective is to understand home network architecture and explore how smart home devices can be represented and connected through a home gateway.

## Devices Used

1. Home Gateway
2. Smartphone
3. IoT Fan
4. IoT Light

## Network Architecture

The Home Gateway is the central networking component represented in the smart home topology.

The smartphone and IoT devices are included to demonstrate a connected home environment.

## Network Design

The topology demonstrates:

- Home gateway integration.
- Smart device connectivity.
- Smartphone connectivity.
- IoT device integration.
- Smart home networking concepts.

## Software Used

Cisco Packet Tracer
