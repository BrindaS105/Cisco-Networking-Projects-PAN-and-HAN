
# HAN – Network Configuration and Implementation

## 1. Overview

The Home Area Network was designed using Cisco Packet Tracer to represent a smart home environment.

The topology includes a Home Gateway, smartphone, IoT fan, and IoT light.

## 2. Network Components

- Home Gateway
- Smartphone
- IoT Fan
- IoT Light

## 3. Network Architecture

The Home Gateway is represented as the central networking component.

The IoT fan and IoT light represent smart appliances within the home environment.

The smartphone is included as a mobile device in the topology.

## 4. Implementation Process

1. Open Cisco Packet Tracer.
2. Add a Home Gateway to the workspace.
3. Add a smartphone.
4. Add an IoT fan.
5. Add an IoT light.
6. Establish the connections represented in the project.
7. Arrange the devices to illustrate the home network.
8. Save the project as HAN.pkt.

## 5. IoT Integration

The topology demonstrates the inclusion of smart home devices within a home networking environment.

The fan and light represent IoT-based home appliances.

## 6. Network Design Observations

The simulation illustrates the relationship between a home gateway and connected home devices.

It provides a visual representation of smart home network architecture.

## 7. Verification

The network topology is represented in the saved Cisco Packet Tracer project.

Specific device control, IP addressing, gateway configuration, and connectivity tests should be documented only if implemented and verified.

## 8. Conclusion

The project provided practical exposure to home network design and IoT device integration using Cisco Packet Tracer.
