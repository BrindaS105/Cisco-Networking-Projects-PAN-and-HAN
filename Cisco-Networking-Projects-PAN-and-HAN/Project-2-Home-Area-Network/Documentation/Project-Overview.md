
# Project Overview – Home Area Network

## Project Title

Design and Simulation of a Smart Home Network Using Cisco Packet Tracer

## Introduction

This project focuses on designing a Home Area Network using Cisco Packet Tracer.

The network represents a smart home environment containing a Home Gateway, smartphone, IoT fan, and IoT light.

## Problem Statement

Modern homes contain multiple connected devices that require network communication and management.

A Home Area Network provides a networking environment for connecting devices within a residential space.

## Project Objectives

- Understand Home Area Network architecture.
- Identify smart home network components.
- Explore home gateway functionality.
- Understand IoT device integration.
- Study connected home networking concepts.

## Devices Included

| Device | Purpose |
|---|---|
| Home Gateway | Central home networking component |
| Smartphone | Mobile device in the network |
| IoT Fan | Smart home appliance |
| IoT Light | Smart lighting device |

## Software

Cisco Packet Tracer

## Expected Outcome

Develop an understanding of smart home network architecture and the relationship between a home gateway and connected IoT devices.

## Conclusion

The project demonstrates the basic design of a smart home network using Cisco Packet Tracer.
