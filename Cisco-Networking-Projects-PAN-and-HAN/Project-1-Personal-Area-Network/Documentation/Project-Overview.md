
# Project Overview – Personal Area Network

## Project Title

Design and Simulation of a Personal Area Network Using Cisco Packet Tracer

## Introduction

This project focuses on designing a small-scale Personal Area Network using Cisco Packet Tracer.

The topology represents a network containing personal computing and mobile devices connected through an access point.

## Problem Statement

Personal electronic devices require convenient network connectivity for communication and information exchange.

A Personal Area Network provides a way to connect compatible personal devices within a limited geographical area.

## Project Objectives

- Understand PAN architecture.
- Identify the components of a personal network.
- Design a PAN topology.
- Explore wireless access point integration.
- Understand personal device connectivity.

## Devices Included

| Device | Purpose |
|---|---|
| PC | Personal computing device |
| Laptop | Portable computing device |
| Smartphone | Mobile communication device |
| Tablet | Portable personal device |
| Access Point | Wireless network access component |

## Software

Cisco Packet Tracer

## Expected Outcome

Develop an understanding of how personal devices can be represented and connected within a PAN topology.

## Conclusion

The project demonstrates the basic structure of a Personal Area Network and provides practical exposure to network topology design.
